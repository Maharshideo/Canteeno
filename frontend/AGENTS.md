# Canteeno Frontend Developer Guidelines

This repository contains the complete frontend for **Canteeno**, a college food ordering and pickup management platform built with TanStack Start, React 19, Tailwind CSS v4, and Zustand.

## Key Principles
- **No Mock Data**: All data is backed by the real Node.js / Express / MongoDB backend API.
- **Real-Time Updates**: Socket.IO client listens to order status transitions and new notifications.
- **Preserved Design System**: Warm campus dining theme, responsive cards, stepper counters, and accessible Radix UI dialogs/drawers.
